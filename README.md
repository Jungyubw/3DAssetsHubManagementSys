# 3DAssetsHubManagementSys

구글 공유 드라이브의 GLB 3D 모델을 AssetHub(assethub.bigbenett.com)에 프로젝트별로 일괄 등록하는 도구.

- 요구사항: [docs/SPEC.md](docs/SPEC.md)
- 일괄 등록 CLI: [assethub-importer/](assethub-importer/)

## 진행 상태

| 명령 | 상태 |
|---|---|
| `inventory` | 미구현 |
| `hub-snapshot` | 미구현 |
| `plan` | 미구현 |
| `apply` | 개발팀 API 명세 대기 |
| `verify` | 개발팀 API 명세 대기 |
